# Contributing to Statlas

Every chart is a folder. The folder tree **is** the website.

```
gallery/
  05-regression-models/          ← family  (NN- prefix sets the order)
    _category.yaml               ← title + summary of the family
    01-coefficient-plot/         ← chart   (NN- prefix sets the order)
      plot.py                    ← the only file you write
      plot.png                   ← generated by build.py
      README.md                  ← generated by build.py
```

## Adding a chart

1. Create `gallery/<family>/<NN-short-slug>/plot.py`.
2. Run `python build.py --only <NN-short-slug> --no-site` to render it, look at `plot.png`.
3. Run `python build.py` to regenerate READMEs and the website in `docs/`.
4. Open a pull request.

## Anatomy of `plot.py`

```python
"""
title: Coefficient plot                       # short, Title case
summary: One sentence shown on the card.      # ≤ 90 characters, ends with a period
r: ggstats::ggcoef_model()                    # closest R equivalent (optional)
tags: [regression, OLS, confidence interval]  # 3–6 search keywords
description: |
  Two short paragraphs. What the chart shows and how to read it,
  then which data and which Python functions are used. `code` and **bold** allowed.
"""
import matplotlib.pyplot as plt
...
plt.show()
```

## Rules

- **Self-contained and offline.** No downloads: no `sns.load_dataset`, no `get_rdataset`, no URLs.
  Use bundled data — `statsmodels.api.datasets.*` (statecrime, fair, spector, engel, co2,
  macrodata, nile, sunspots, star98, anes96, …), `sklearn.datasets.load_*` (wine, iris,
  diabetes, breast_cancer), `lifelines.datasets.load_*` (rossi, lung, gbsg2, waltons, …) —
  or a simulation seeded with `np.random.default_rng(<int>)`.
- **Libraries:** numpy, pandas, matplotlib, seaborn, scipy, statsmodels, scikit-learn, lifelines.
- **Statistics on the chart.** Report the test, statistic, p-value, effect size or interval that
  makes the chart *statistical*. Use a grey subtitle line under the title:

  ```python
  ax.set_title("A sentence that states the finding", pad=26)
  ax.text(0, 1.02, "Welch's t(48.2) = 3.1, p = .003, d = 0.84 · n = 120",
          transform=ax.transAxes, fontsize=9.5, color="#6E6E73")
  ```
- **Style.** Don't set fonts, spines or grid globally — `build.py` applies `statlas.mplstyle`.
  Use the palette in that order: `#007AFF` blue, `#FF9500` orange, `#34C759` green,
  `#FF3B30` red, `#AF52DE` purple, `#5AC8FA` teal; greys `#8E8E93`, `#AEAEB2`, `#C7C7CC`,
  text `#1D1D1F` / `#3A3A3C` / `#6E6E73`. Sequential: `"Blues"`/`"viridis"`;
  diverging: `"RdBu_r"` or `sns.diverging_palette(250, 25, as_cmap=True)`.
- **Readable code.** 30–80 lines, top-to-bottom, short comments for each step, no helper
  frameworks. One figure per script, ending with `plt.show()`. Typical size `figsize=(8, 5)`;
  multi-panel up to `(11, 7)`.
- **No overlaps.** Look at the PNG: labels must not collide with each other or with data.

## Translations

The website is available in English, French, Japanese and Mandarin. Interface strings and
chart titles/descriptions live in `i18n/<lang>.yaml`. After adding a chart, run
`python build.py --export-i18n` to refresh `i18n/_source.yaml`, then add the new chart's
`title`, `summary` and `description` under `examples:` in each language file (missing
entries fall back to English).
