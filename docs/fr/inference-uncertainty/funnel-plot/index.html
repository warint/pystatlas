Galerie/Inférence et incertitude

Graphique en entonnoir

Les petites études « Pygmalion » sont-elles plus optimistes ? 19 effets des attentes des enseignants en fonction de leur erreur type, avec entonnoir pseudo-95 % et test d'Egger.

Par Thierry Warin · fait partie de PyStatlas

Chaque point est une étude : sa taille d'effet en abscisse, son erreur type en ordonnée (axe inversé), de sorte que les grandes études précises se trouvent en haut. En l'absence de biais, les points forment un entonnoir symétrique autour de l'effet combiné, dont 95 % se situent dans la région de pseudo-confiance (± 1,96 erreur type). S'il manque de petites études aux résultats nuls ou négatifs — biais de publication —, le bas de l'entonnoir est déséquilibré. Le test de régression d'Egger (écart normal réduit régressé sur la précision) quantifie cette asymétrie ; sa droite ajustée est en tirets.

Les données sont les 19 expériences sur les attentes des enseignants (effet « Pygmalion ») de Raudenbush (1984) : différences de moyennes standardisées du QI des élèves et leurs variances d'échantillonnage, saisies telles que publiées dans dat.raudenbush1985 du paquet R metafor. Les études les moins précises rapportent les effets les plus forts, et l'ordonnée à l'origine d'Egger est à la limite de la significativité. Une asymétrie ne prouve pas un biais de publication : ici, les petites études sont pour la plupart celles où les enseignants connaissaient leurs élèves depuis une semaine ou moins, situation dont Raudenbush a montré qu'elle produit des effets réellement plus forts. Le test d'Egger est une régression MCO de statsmodels.

Le code et le texte à l'intérieur des figures sont en anglais.

Équivalent Rmetafor::funnel() + metafor::regtest()

import matplotlib.pyplot as plt
import numpy as np
import statsmodels.api as sm

# Teacher-expectancy experiments (Raudenbush, 1984): standardised mean difference
# in pupil IQ and its sampling variance, as in metafor's dat.raudenbush1985
dp = np.array([0.03, 0.12, -0.14, 1.18, 0.26, -0.06, -0.02, -0.32, 0.27, 0.80, 0.54, 0.18,
               -0.02, 0.23, -0.18, -0.06, 0.30, 0.07, -0.07])
vi = np.array([0.0156, 0.0216, 0.0279, 0.1391, 0.1362, 0.0106, 0.0106, 0.0484, 0.0269, 0.0630,
               0.0912, 0.0497, 0.0835, 0.0841, 0.0253, 0.0279, 0.0193, 0.0088, 0.0303])
sp = np.sqrt(vi)

# Fixed-effect pooled estimate and Egger's test: z = b0 + b1 · precision
w = 1 / sp**2
pooled = np.sum(w * dp) / w.sum()
egger = sm.OLS(dp / sp, sm.add_constant(1 / sp)).fit()
b0, b1 = egger.params

fig, ax = plt.subplots(figsize=(9, 5.6))
s_grid = np.linspace(0, sp.max() * 1.1, 100)
ax.fill_betweenx(s_grid, pooled - 1.96 * s_grid, pooled + 1.96 * s_grid, color="#007AFF",
                 alpha=0.07, lw=0)
for sign in (-1, 1):
    ax.plot(pooled + sign * 1.96 * s_grid, s_grid, color="#8E8E93", lw=1, ls="--",
            label="Pseudo 95% CI\n(pooled ± 1.96 SE)" if sign > 0 else None)
ax.axvline(pooled, color="#007AFF", lw=1.2, label=f"Pooled (fixed effect)\nd = {pooled:.2f}")
ax.axvline(0, color="#C7C7CC", lw=0.8)
ax.plot(b1 + b0 * s_grid, s_grid, color="#FF9500", lw=1.8, ls="--", label="Egger regression line")

ax.scatter(dp, sp, s=40, color="#007AFF", edgecolor="white", lw=0.7, zorder=3,
           label=f"Studies ({len(dp)})")

ax.invert_yaxis()
ax.set_ylim(sp.max() * 1.1, 0)
ax.set_xlim(-0.9, 1.4)
ax.set_xlabel("Standardised mean difference in IQ, expectancy vs control (d)")
ax.set_ylabel("Standard error")
ax.grid(axis="y", visible=False)

handles, labels = ax.get_legend_handles_labels()
order = [3, 1, 2, 0]
ax.legend([handles[i] for i in order], [labels[i] for i in order], loc="upper left",
          bbox_to_anchor=(1.01, 1), fontsize=9, labelspacing=1)

ax.set_title("Small studies report larger effects — " + ("Egger's test flags asymmetry"
             if egger.pvalues[0] < 0.05 else "but Egger's test is borderline"), pad=26)
ax.text(0, 1.02, f"Egger's test: intercept = {b0:.2f}, t({egger.df_resid:.0f}) = "
        f"{egger.tvalues[0]:.2f}, p = {egger.pvalues[0]:.3f} · k = {len(dp)} teacher-expectancy "
        f"studies (Raudenbush, 1984)", transform=ax.transAxes, fontsize=9.5, color="#6E6E73")
plt.show()
