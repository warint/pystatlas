Carte choroplèthe avec pondérations spatiales

Une carte d'une variable avec, par-dessus, le réseau des voisins — la structure sur laquelle repose toute statistique spatiale.

Par Thierry Warin · fait partie de PyStatlas

Toute statistique spatiale commence par décider qui est voisin de qui. Ce graphique montre cette décision avant tout test : une carte choroplèthe d'une variable, avec une ligne entre les centres de chaque paire de zones voisines. Ici, deux zones sont voisines si elles partagent une frontière ou un coin (contiguïté de type reine) ; chaque ligne de la matrice de pondérations est ensuite standardisée, de sorte que le « décalage spatial » d'une zone est la moyenne de ses voisines. D'autres choix — contiguïté de type tour, k plus proches voisins, bande de distance — donnent d'autres réseaux et peuvent changer les résultats : le réseau mérite d'être regardé.

Les données sont l'Essai sur la statistique morale de la France d'André-Michel Guerry (1833) : 85 départements vers 1830, tels que préparés par le Center for Spatial Data Science et chargés avec libpysal (examples.load_example("Guerry"), téléchargés une fois puis conservés). La variable est le pourcentage de conscrits sachant lire et écrire. Les pondérations viennent de libpysal.weights.Queen ; la carte est dessinée avec GeoPandas.

Le code et le texte à l'intérieur des figures sont en anglais.

Équivalent Rspdep::poly2nb() + plot(nb, coords)

import geopandas as gpd
import matplotlib.pyplot as plt
import numpy as np
from libpysal import examples, weights

# Data: 85 French départements, c. 1830 (Guerry, 1833)
g = gpd.read_file(examples.load_example("Guerry").get_path("guerry.shp"))
y = g["Litercy"]                      # % of conscripts who can read and write

# Queen contiguity: neighbours share a border or a corner
w = weights.Queen.from_dataframe(g, use_index=False)
cards = np.array(list(w.cardinalities.values()))
xy = np.column_stack([g.centroid.x, g.centroid.y])

fig, ax = plt.subplots(figsize=(8, 7.4))
g.plot(column=y, cmap="Blues", edgecolor="white", linewidth=0.6, ax=ax, legend=True,
       legend_kwds=dict(label="Conscripts who can read and write (%)", shrink=0.6, pad=0.01))
for i, nbrs in w.neighbors.items():
    for j in nbrs:
        if i < j:                      # draw each link once
            ax.plot(*xy[[i, j]].T, color="#FF9500", lw=0.8, alpha=0.8)
ax.scatter(*xy.T, s=10, color="#1D1D1F", zorder=3)
ax.set_axis_off()
ax.set_title(f"Each département has {w.mean_neighbors:.1f} neighbours on average", pad=26)
ax.text(0, 1.02, f"Queen contiguity · n = {w.n} départements · {int(w.s0 / 2)} links · "
        f"{cards.min()} to {cards.max()} neighbours · Guerry (1833)",
        transform=ax.transAxes, fontsize=9.5, color="#6E6E73")
plt.show()

Les figures utilisent le style PyStatlas (facultatif) : ajoutez plt.style.use("pystatlas.mplstyle") pour obtenir exactement le même rendu.
