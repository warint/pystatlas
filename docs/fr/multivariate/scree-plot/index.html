Diagramme des valeurs propres

Combien de dimensions décrivent les compétences numériques de 300 professions ? Variance par composante et seuil d'analyse parallèle.

Par Thierry Warin · fait partie de PyStatlas

Combien de composantes principales vaut-il la peine de conserver ? Les barres montrent la part de variance portée par chaque composante, la ligne orange le cumul. La ligne grise en tirets correspond à l'analyse parallèle de Horn : le 95e centile des mêmes valeurs propres calculées sur des données aléatoires non corrélées de même taille. Une composante n'est retenue (en bleu) que si elle dépasse ce plancher de bruit ; la ligne pointillée indique l'ancienne règle de Kaiser (valeur propre > 1).

Le cadre est celui d'Aubert, Bourdeau, Warin, Schneider et Sénegas (2026), « Digital skills assessment in jobs in Canada » (Journal for Labour Market Research) : 300 professions, chacune notée sur 10 indicateurs de compétences numériques (logiciels de bureautique, saisie de données, recherche sur le Web, courriel, collaboration en ligne, réseaux sociaux, création de contenu, analyse de données, programmation, cybersécurité). Les scores sont simulés avec numpy (graine fixe) à partir de trois dimensions latentes de compétences et d'une quatrième, faible, à titre d'illustration ; ce ne sont pas les données ni les résultats de l'article. Les valeurs propres de la matrice de corrélation sont calculées par numpy.linalg.eigvalsh ; l'analyse parallèle repose sur 500 simulations à graine fixe. Comme souvent, l'analyse parallèle est plus stricte que la règle de Kaiser : la faible quatrième dimension dépasse λ > 1, mais pas le plancher de bruit.

Le code et le texte à l'intérieur des figures sont en anglais.

import matplotlib.pyplot as plt
import numpy as np
from sklearn.preprocessing import StandardScaler

# Simulated data, set in the context of Aubert et al. (2026) [aubert2026]
# 300 occupations x 10 digital-skill scores driven by 3 latent skills (+ a weak 4th)
rng = np.random.default_rng(2026)
F = rng.normal(size=(300, 4))  # basic office, communication, advanced technical, weak niche
L = np.array([[.8, 0, 0, 0], [.75, 0, 0, 0], [.6, .3, 0, 0], [.5, .5, 0, 0], [.2, .7, .1, .5],
              [0, .75, 0, 0], [0, .6, .3, -.5], [.2, 0, .75, 0], [0, 0, .8, 0], [0, .1, .6, .5]])
X = StandardScaler().fit_transform(F @ L.T + rng.normal(0, 0.55, (300, 10)))
n, p = X.shape
eig = np.sort(np.linalg.eigvalsh(np.corrcoef(X.T)))[::-1]  # PCA eigenvalues
pct = 100 * eig / eig.sum()

# Horn's parallel analysis: eigenvalues of pure noise, 95th percentile
rng = np.random.default_rng(42)
sims = [np.sort(np.linalg.eigvalsh(np.corrcoef(rng.normal(size=(n, p)).T)))[::-1]
        for _ in range(500)]
pa = np.percentile(sims, 95, axis=0)
keep = eig > pa
k = np.arange(1, p + 1)

fig, ax = plt.subplots(figsize=(8, 5))
ax.bar(k, pct, width=0.68, color=np.where(keep, "#007AFF", "#C7C7CC"), zorder=2)

# Cumulative share, parallel-analysis floor and Kaiser threshold (all in % of variance)
cum = np.cumsum(pct)
ax.plot(k, cum, color="#FF9500", marker="o", ms=5, mfc="white", mew=1.5, zorder=3)
ax.annotate(f"{cum[keep.sum() - 1]:.0f}% with {keep.sum()} components",
            (keep.sum(), cum[keep.sum() - 1]), xytext=(12, -16), textcoords="offset points",
            fontsize=9.5, color="#FF9500", fontweight="semibold")
ax.text(p, cum[-1] - 4, "cumulative", fontsize=8.5, color="#FF9500", ha="center", va="top")
ax.plot(k, 100 * pa / p, color="#6E6E73", ls="--", lw=1.4, zorder=3)
ax.text(4.6, 100 * pa[4] / p + 1.5, "parallel analysis (noise, 95th pct.)", fontsize=8.5,
        color="#6E6E73", va="bottom")
ax.axhline(100 / p, color="#8E8E93", ls=":", lw=1.2, zorder=1)
ax.text(p + 0.4, 100 / p + 0.8, "Kaiser λ > 1", fontsize=8.5, color="#8E8E93", ha="right", va="bottom")

ax.set_xticks(k, [f"PC{i}\n{v:.1f}%" for i, v in zip(k, pct)], fontsize=8.5)
ax.set_xlim(0.4, p + 0.6)
ax.set_ylim(0, 105)
ax.set_ylabel("Variance explained (%)")
ax.set_title(f"Parallel analysis retains {keep.sum()} of {p} components; Kaiser would keep "
             f"{(eig > 1).sum()}", pad=26)
ax.text(0, 1.02, f"PCA of {p} skill scores · n = {n} occupations (simulated) · λ = "
        f"{', '.join(f'{e:.2f}' for e in eig[:4])}, … · PA: 500 simulations",
        transform=ax.transAxes, fontsize=9.5, color="#6E6E73")
plt.show()
