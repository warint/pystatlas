Prévision SARIMA

Prévision ARIMA saisonnière des ventes manufacturières mensuelles, avec intervalles à 80 % et 95 % face aux données mises de côté.

Par Thierry Warin · fait partie de PyStatlas

Une prévision n'est honnête qu'accompagnée de son incertitude. L'éventail foncé est l'intervalle de prédiction à 80 %, l'éventail clair l'intervalle à 95 % ; tous deux s'élargissent à mesure que l'horizon s'éloigne. Les deux dernières années ont été mises de côté lors de l'ajustement : les points montrent donc ce qui s'est réellement produit, et le sous-titre rapporte la RMSE hors échantillon ainsi que le nombre de ces mois tombés dans l'intervalle à 95 %.

Le contexte est celui de Warin (2024, Technology Innovations in Statistics Education), sur l'utilisation des données économiques ouvertes de Statistique Canada dans les cours de statistique, où les ventes mensuelles du secteur manufacturier sont une série d'enseignement typique. Les données sont ici simulées à titre d'illustration et ne sont pas les chiffres de Statistique Canada : une série semblable aux ventes manufacturières, en milliards de dollars, de janvier 2005 à décembre 2023 (228 mois), construite à partir d'une tendance avec deux creux (2009 et printemps 2020), d'un profil mensuel fixe et d'un bruit. La même série simulée sert aux exemples STL, SARIMA et sous-séries saisonnières. Le modèle est ajusté sur 2005–2021 et prévoit les 24 mois de 2022–2023. Il s'agit d'un ARIMA saisonnier (1,1,1)(0,1,1)₁₂ — la structure classique dite « airline » — ajusté avec statsmodels.tsa.statespace.SARIMAX ; les intervalles proviennent de get_forecast().conf_int().

Le code et le texte à l'intérieur des figures sont en anglais.

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from statsmodels.tsa.statespace.sarimax import SARIMAX

# Simulated data, set in the context of Warin (2024) [warin2024statcan]

# Data: simulated monthly manufacturing sales, billions of dollars, 2005–2023 (shared generator)
rng = np.random.default_rng(2024)
idx = pd.date_range("2005-01-01", "2023-12-01", freq="MS")
t = np.arange(len(idx))
trend = 48 + 0.06 * t - 7 * np.exp(-((t - 54) / 9) ** 2) - 8 * np.exp(-((t - 183) / 2.5) ** 2)
season = np.tile([-3.0, -0.8, 2.6, 0.6, 1.2, 2.2, -3.4, -1.2, 1.6, 2.0, 0.4, -2.2], len(idx) // 12)
sales = pd.Series(trend + season + rng.normal(0, 0.7, len(idx)), index=idx)
h = 24                                                  # hold out the last two years
train, test = sales[:-h], sales[-h:]

# Fit a seasonal ARIMA and forecast the held-out horizon
fit = SARIMAX(train, order=(1, 1, 1), seasonal_order=(0, 1, 1, 12)).fit(disp=False)
fc = fit.get_forecast(h)
mean, ci95, ci80 = fc.predicted_mean, fc.conf_int(alpha=0.05), fc.conf_int(alpha=0.20)

rmse = np.sqrt(((test - mean) ** 2).mean())
mae = (test - mean).abs().mean()                  # mean absolute error
covered = ((test >= ci95.iloc[:, 0]) & (test <= ci95.iloc[:, 1])).sum()

fig, ax = plt.subplots(figsize=(9, 5))
hist = train["2014":]
ax.plot(hist.index, hist, color="#1D1D1F", lw=1.4, label="Observed (training)")
ax.fill_between(mean.index, ci95.iloc[:, 0], ci95.iloc[:, 1], color="#007AFF", alpha=0.15, lw=0,
                label="95% prediction interval")
ax.fill_between(mean.index, ci80.iloc[:, 0], ci80.iloc[:, 1], color="#007AFF", alpha=0.28, lw=0,
                label="80% prediction interval")
ax.plot(mean.index, mean, color="#007AFF", lw=2, label="Forecast")
ax.scatter(test.index, test, s=16, color="#FF9500", edgecolor="white", lw=0.6, zorder=4,
           label="Held-out actuals")

# Mark the forecast origin
ax.axvline(test.index[0], color="#AEAEB2", lw=1, ls="--")
ax.text(test.index[0], 0.97, "  forecast origin", transform=ax.get_xaxis_transform(),
        fontsize=9, color="#8E8E93", va="top")

ax.set(ylabel="Manufacturing sales (billions of dollars)", xlim=(hist.index[0], test.index[-1]))
ax.legend(loc="upper left", ncols=3)
ax.set_ylim(top=mean.max() + 12)
ax.set_title(f"A seasonal ARIMA tracks sales two years ahead, off by {mae:.1f} bn on average", pad=26)
ax.text(0, 1.02, f"SARIMA(1,1,1)(0,1,1)₁₂ · AIC = {fit.aic:.0f} · RMSE = {rmse:.2f} bn over {h} held-out "
        f"months (simulated) · {covered}/{h} actuals inside the 95% PI",
        transform=ax.transAxes, fontsize=9.5, color="#6E6E73")
plt.show()
