空間データ

近隣の値が高いところでは、その値も高いのか。空間重み、大域的・局所的な空間自己相関、そしてクラスターの広がりを、1830 年代のゲリーのフランスで示します。

空間データ

空間重み付きコロプレス図

1 つの変数の地図に近隣ネットワークを重ねた図。あらゆる空間統計の土台となる構造です。

spdep::poly2nb() + plot(nb, coords)
空間データ

モラン散布図（大域的自己相関）

各地域をその近隣の平均と比べ、モランの I、並べ替え検定、参照分布を添えます。

spdep::moran.plot() + spdep::moran.mc()
空間データ

LISA クラスター地図（局所的自己相関）

クラスターと空間的外れ値がどこにあるか。各地域の局所モラン I を、並べ替えによる有意性とともに地図に示します。

spdep::localmoran_perm() / rgeoda::local_moran()
空間データ

空間コレログラム

近隣の次数を広げながらモランの I を求め、並べ替えによる包絡線を添えます。空間的なクラスターがどこまで及ぶかを示します。

spdep::sp.correlogram(method = "I")
