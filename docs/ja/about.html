PyStatlas について

答える問いごとに整理した、Python の統計グラフ集です。分布やグループ比較から回帰、生存分析、機械学習まで、すべての図に推定値、信頼区間、検定、効果量といった根拠となる統計量を示します。

PyStatlas は、コードからではなく、研究者が立てる問いから出発します。もともとは、自分の分野をよく知り、データで問いに答える必要がある社会科学の学生のために作られました。これらのグループに差はあるか、2 つの変数は連動しているか、モデルは何を予測し、それはなぜか。各グラフは必要な統計量を図の上に示し、Python の科学計算エコシステムで書かれた短く自己完結したスクリプトを添えています。R の ggstats や ggstatsplot と同じ考え方です。

基本方針

  • 単体で動作。すべてのスクリプトはそのまま実行できます。データは同梱データセット（statsmodels、scikit‑learn、lifelines）またはシード固定のシミュレーションを使用し、ダウンロードは不要です。
  • 統計が第一。各グラフには、推定値、区間、検定統計量、効果量といった重要な数値が示されています。
  • フォルダ＝ページ。リポジトリの構成はサイトの構成と一致しています。各例は gallery/<family>/<chart>/plot.py に置かれ、描画済みの plot.png と README が付属します。

カテゴリ

カテゴリグラフ数内容
分布5ヒストグラム、密度曲線、リッジラインプロット、ECDF、Q–Q プロットでデータの形をとらえます。
群間比較5検定、効果量、p値をグラフ上に示して群を比較します。ggstatsplot のスタイルです。
割合と調査データ5割合、クロス集計、リッカート尺度を、ggstats::gglikert や stat_prop の流儀で描きます。
相関と関連4相関行列、統計量付き散布図、変数ペア間の関係を描きます。
回帰モデル6係数プロット、オッズ比、モデル比較、限界効果。Python 版の ggcoef_model です。
モデル診断5残差、てこ比、キャリブレーション、ROC 曲線。モデルを信頼する前に確認しましょう。
生存時間分析4リスク集合表付きのカプラン・マイヤー曲線、累積ハザード、Cox モデルのハザード比。
時系列4分解、自己相関、予測区間付きの予測、時間的変化を描きます。
多変量解析とクラスタリング4高次元データのための PCA バイプロット、スクリープロット、クラスタリング、ヒートマップ。
推測と不確実性6ブートストラップ、信頼区間、検出力、一致度、メタアナリシスのフォレストプロット。
機械学習9モデルは新しいデータをどれだけうまく予測できるのか、そしてなぜか。交差検証による評価、学習曲線、モデルに依存しない説明を、それぞれの不確実性とともに示します。

謝辞

PyStatlas は、オープンソースソフトウェア、オープンデータ、そして R コミュニティの成果の上に成り立っています。すべての例は、以下の成果を用いて、あるいはそれに着想を得て作られています。

例で使用している Python パッケージ

NumPy · pandas · Matplotlib · seaborn · SciPy · statsmodels · scikit-learn · lifelines · SHAP

データセット

  • scikit-learn toy datasets — Breast Cancer Wisconsin, Iris, Diabetes, Wine, Digits
  • statsmodels datasets — El Niño, Engel food expenditure, ANES 1996, Fair's affairs, US state crime, Spector, Mauna Loa CO₂, sunspots
  • lifelines datasets — NCCTG lung cancer, Rossi recidivism, GBSG2 breast cancer
  • BCG vaccine trials (Colditz et al., 1994), as distributed in R's metafor (dat.bcg)

着想を得たプロジェクト

  • The R Graph Gallery (Yan Holtz)
  • ggstatsplot (Indrajeet Patil) — ggbetweenstats(), ggwithinstats(), ggbarstats(), ggcorrmat(), ggscatterstats()
  • ggstats (Joseph Larmarange) — gglikert(), stat_prop(), ggtable(), ggcoef_model(), ggcoef_compare()
  • ggdist (Matthew Kay) and ggrain (Nicholas Judd, Jordy van Langen) — stat_halfeye(), geom_rain()
  • ggridges (Claus O. Wilke) — geom_density_ridges()
  • survminer and factoextra (Alboukadel Kassambara) — ggsurvplot(), ggforest(), ggadjustedcurves(), fviz_pca_biplot(), fviz_eig(), fviz_silhouette()
  • dabestr (Joses W. Ho and colleagues) — dabest()
  • performance, easystats (Daniel Lüdecke and colleagues) — check_model()
  • metafor (Wolfgang Viechtbauer) — forest(), funnel(), regtest()
  • GGally (Barret Schloerke, Di Cook) — ggpairs()
  • corrplot (Taiyun Wei, Viliam Simko) — corrplot()
  • SHAP (Scott Lundberg and Su-In Lee, 2017) and shapviz (Michael Mayer) — sv_importance(), sv_dependence(), sv_waterfall()
  • vip and pdp (Brandon Greenwell, Bradley Boehmke) and tidymodels' yardstick — vip(), partial(), conf_mat(), pr_curve()
