PyStatlas について

社会科学の実際の研究上の問いを舞台に、答える問いごとに整理した Python の統計グラフ集です。モデルの予測精度とその理由を示す機械学習、地図と空間的自己相関を扱う空間データを、分布、グループ比較、回帰、生存分析と並べて収録し、すべての図に推定値、信頼区間、検定、効果量といった根拠となる統計量を示します。

PyStatlas は、コードからではなく、研究者が立てる問いから出発します。もともとは、自分の分野をよく知り、データで問いに答える必要がある社会科学の学生のために作られました。これらのグループに差はあるか、2 つの変数は連動しているか、モデルは何を予測し、それはなぜか。各グラフは必要な統計量を図の上に示し、Python の科学計算エコシステムで書かれた短く自己完結したスクリプトを添えています。R の ggstats や ggstatsplot と同じ考え方です。

基本方針

  • 単体で動作。すべてのスクリプトはそのまま実行できます。ほとんどの例は、グラフの下に引用した著者の既発表論文の文脈に置かれ、シード固定の小さなシミュレーションで動きます。手法を示すのに足りるだけのデータであり、論文のデータや結果ではありません。空間データの例は、スクリプト内で作成した五大湖・セントローレンス回廊の模式的な地図を使います。メタ分析のフォレストプロットとファンネルプロットは実データ（手入力した公表済みの表）を使います。
  • 統計が第一。各グラフには、推定値、区間、検定統計量、効果量といった重要な数値が示されています。
  • フォルダ＝ページ。リポジトリの構成はサイトの構成と一致しています。各例は gallery/<family>/<chart>/plot.py に置かれ、描画済みの plot.png と README が付属します。
