回帰モデル

係数プロット、オッズ比、モデル比較、限界効果。Python 版の ggcoef_model です。

回帰モデル

係数プロット

回帰係数の推定値を 95% 信頼区間とともに、項ごとに1行で示します。

ggstats::ggcoef_model()
回帰モデル

オッズ比のフォレストプロット

ロジスティック回帰のオッズ比を対数スケールで描き、OR [95% CI] の表を並べます。

ggstats::ggcoef_model(exponentiate = TRUE)
回帰モデル

入れ子モデルの比較

学区の数学の成績に関する 3 つの入れ子回帰の係数を並べ、ブロックを追加するにつれて推定値がどう動くかを見ます。

ggstats::ggcoef_compare()
回帰モデル

予測確率

モデルに基づく確率曲線を、群ごとに 95% 信頼帯とともに説明変数の範囲にわたって描きます。

ggeffects::ggpredict() / marginaleffects::plot_predictions()
回帰モデル

交互作用効果

平均 ± 1 SD における単純傾斜とジョンソン・ネイマン・プロット。大学進学準備コースと数学の成績の関係を、児童の貧困が調整します。

interactions::interact_plot() / interactions::johnson_neyman()
回帰モデル

分位点回帰プロセス

条件付き分布にわたって傾きがどう変化するかを、単一の OLS 推定値と比較します。

quantreg::plot(summary(rq(tau = 1:19 / 20)))
