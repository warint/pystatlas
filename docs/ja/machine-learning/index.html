機械学習

モデルは新しいデータをどれだけうまく予測できるのか、そしてなぜか。交差検証による評価、学習曲線、モデルに依存しない説明を、それぞれの不確実性とともに示します。

機械学習

指標付き混同行列

分類器がツイートを環境・社会・ガバナンスのトピックにどれだけ正しく振り分けるか。交差検証による 3 × 3 の混同行列に、指標のブートストラップ区間を添えます。

yardstick::conf_mat() + autoplot()
機械学習

適合率–再現率曲線

COVID-19 のフェイクニュースを共有する Facebook ユーザーを予測する 2 つの分類器の、交差検証による適合率–再現率曲線。平均適合率と無技能の基準線を示します。

yardstick::pr_curve() + autoplot()
機械学習

学習曲線

学習データが増えるにつれての学習時正解率と交差検証正解率。COVID-19 のフェイクニュースを共有する Facebook ユーザーを予測する 2 つのモデルで比べます。

caret::learning_curve_dat() + ggplot()
機械学習

交差検証によるモデル比較

生産ロットの廃棄率を予測する 6 つのモデルの分割ごとの R²。平均と補正済み 95% 区間を添えます。

caret::resamples() + bwplot() / tune::autoplot()
機械学習

置換重要度

ランダムフォレストがロットの廃棄率の予測でどの工程特徴量に頼っているか。各特徴量をシャッフルしたときのテスト R² の低下で示します。

vip::vip(method = "permute")
機械学習

ICE 曲線付き部分依存プロット

ロットの予測廃棄率が機械速度と前回保守からの日数によってどう変わるか。ロットごとの曲線（ICE）に重ねた平均（PDP）で示します。

pdp::partial(ice = TRUE) + autoplot() / iml::FeatureEffect

応用：SHAP による説明

シャープレイ値は、各予測を特徴量ごとの加法的な寄与に分解します。全体として、特徴量ごとに、そして個々のケースについて。

機械学習 · 応用：SHAP による説明

SHAP サマリー（ビースウォーム）

各生産ロットの各工程特徴量の SHAP 値を、その特徴量の値で色分けし、平均 |SHAP| による重要度を添えて示します。

shapviz::sv_importance(kind = "beeswarm")
機械学習 · 応用：SHAP による説明

SHAP 依存プロット

前回保守からの日数が各ロットの予測廃棄率にどう寄与するか。最も強い交互作用の相手で色分けし、平滑化した傾向線を添えます。

shapviz::sv_dependence()
機械学習 · 応用：SHAP による説明

1 件の予測に対する SHAP ウォーターフォール

廃棄の多い 1 つのロットについて、各工程特徴量が予測廃棄率を平均からモデルの出力までどう動かすかを示します。

shapviz::sv_waterfall()
