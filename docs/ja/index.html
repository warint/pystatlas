統計グラフ 61 種 · 12 カテゴリ · 100% Python

社会データサイエンスを、
美しく Python で。

社会科学の実際の研究上の問いを舞台に、答える問いごとに整理した Python の統計グラフ集です。モデルの予測精度とその理由を示す機械学習、地図と空間的自己相関を扱う空間データを、分布、グループ比較、回帰、生存分析と並べて収録し、すべての図に推定値、信頼区間、検定、効果量といった根拠となる統計量を示します。

多くの Python 教材は、まずコードを教え、問いは後回しにします。このギャラリーはその逆です。もともとは社会科学を学ぶ学生のために作られましたが、自分の分野をよく知り、答えるべき問いを持つすべての人に役立ちます。これらのグループに差はあるか、2 つの変数は連動しているか、モデルはなぜこう予測したのか。問いから出発し、それに答えるグラフを見つけ、示された統計量を読み取り、必要なコードだけを持ち帰ってください。
