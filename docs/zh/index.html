57 张统计图表 · 11 个类别 · 100% Python

统计之美，
尽在 Python。

按所回答的问题组织的 Python 统计图表。从分布与组间比较，到回归、生存分析和机器学习，每张图都给出其背后的统计量——估计值、置信区间、检验和效应量。

大多数 Python 学习资源先教代码，把问题留到以后。本图库反其道而行之。它最初是为社会科学专业的学生编写的，也适合所有熟悉自己领域、手头有问题要回答的人：这些组之间有差异吗？这两个变量是否同步变化？模型为什么作出这样的预测？从问题出发，找到能回答它的图表，读懂图上给出的统计量，只取你需要的代码。
