关于 PyStatlas

精心编排的 Python 统计图表图集——回归模型、Likert 量表、生存曲线、模型诊断等应有尽有。选一张图，复制代码，即可完成。

PyStatlas 之于 Python，正如 R Graph Gallery、ggstats 和 ggstatsplot 之于 R：一本统计图表目录——模型系数、Likert 量表、生存曲线、模型诊断、效应量——每张图都配有基于科学计算 Python 生态、简洁且可直接复制粘贴的代码。

设计原则

  • 自成一体。每个脚本都可直接运行。数据来自库中自带的数据集（statsmodels、scikit‑learn、lifelines）或设定了随机种子的模拟——无需下载。
  • 统计优先。每张图表都标注了关键数字：估计值、区间、检验统计量和效应量。
  • 文件夹即页面。代码仓库的目录树与网站结构一一对应。每个示例都位于 gallery/<family>/<chart>/plot.py，并附有渲染好的 plot.png 和 README。

图表类别

类别图表内容概览
分布5看清数据的形态：直方图、密度图、山脊图、ECDF 与 Q–Q 图。
组间比较5以 ggstatsplot 的方式比较各组，将检验、效应量和 p 值直接标注在图上。
比例与问卷调查5比例、交叉表与 Likert 量表，延续 ggstats::gglikert 与 stat_prop 的风格。
相关与关联4相关矩阵、附带统计量的散点图以及变量两两之间的关系。
回归模型6系数图、优势比、模型比较与边际效应——Python 版的 ggcoef_model。
模型诊断5残差、杠杆值、校准与 ROC 曲线：先检验，再信任模型。
生存分析4附风险表的 Kaplan–Meier 曲线、累积风险以及 Cox 模型风险比。
时间序列4序列分解、自相关、带预测区间的预测以及随时间的变化。
多元分析与聚类4面向高维数据的 PCA 双标图、碎石图、聚类与热图。
推断与不确定性6自助法（Bootstrap）、置信区间、统计功效、一致性分析与元分析森林图。
